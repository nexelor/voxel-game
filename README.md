I am developping this on a cachyos arch based system.

This is a voxel like game using Vulkan in c++. Ultimately, I want to mix some aspect of Minecraft, like the survival and creativity aspect, and crafting mechanics from Vintage Story, like the "pixel" carving of clay in-world.

My future goal is to have multiple complex crafting system: usual crafting table, furnace, specific machine, multiblock, in-world crafting (e.g. throw in water, interact on a block, etc.), magic system like Bewitchment but with my own twist, etc.
